
# Inventory Management API

A RESTful Inventory Management API built with Python and FastAPI to help businesses manage products, track stock movements, and monitor inventory levels.

## Project Overview

This project provides a backend system for managing inventory operations. It allows users to create and manage products, record stock movements, view transaction history, and identify products that need restocking.

## Features

- Create, update, retrieve, and delete products
- Search and filter products
- Track stock in and stock out operations
- Prevent stock from becoming negative
- Maintain inventory transaction history
- Identify low stock products
- Validate incoming data
- Automated API testing

## Technologies Used

| Technology | Purpose |
|---|---|
| Python | Programming language |
| FastAPI | REST API framework |
| SQLite | Database |
| SQLAlchemy | Database ORM |
| Pydantic | Data validation |
| Pytest | Automated testing |

## Installation and Setup

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd inventory-management-api
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python -m uvicorn app.main:app --reload
```

Run tests:

```bash
python -m pytest -v
```
